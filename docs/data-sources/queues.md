# ably_queues (Data Source)

The `ably_queues` data source lists every queue in an Ably app, including queues Terraform does not manage, with their connection details and live message counts. Use `ably_queue` to look up a single queue by id or name.


## Example Usage

```terraform
# Look up a queue and use its AMQP connection details.
data "ably_queue" "events" {
  app_id = data.ably_app.existing.id
  name   = "events"
}

output "events_queue_amqp_uri" {
  value     = data.ably_queue.events.amqp.uri
  sensitive = true
}

data "ably_queues" "all" {
  app_id = data.ably_app.existing.id
}
```
