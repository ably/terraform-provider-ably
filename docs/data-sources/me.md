# ably_me (Data Source)

The `ably_me` data source describes the token the provider is configured with, and the account and user it belongs to. It is the way to reference your account ID without hardcoding it.


## Example Usage

```terraform
# Describes the token the provider is configured with, and the account it
# belongs to. Useful for referencing your account ID without hardcoding it.
data "ably_me" "current" {}

output "account_id" {
  value = data.ably_me.current.account.id
}
```
